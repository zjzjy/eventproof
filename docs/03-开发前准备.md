## 2. 开发前真正需要你做的三件事

### 2.1 定模型（已配置）

已配置阿里云百炼（DashScope OpenAI 兼容接口）：

```env
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL_FAST=qwen3.8-flash
LLM_MODEL_STRONG=qwen3.8-flash
LLM_MAX_SPEND_CNY=10
LLM_HARD_STOP_CNY=8
```

已完成最小连通性 + JSON 抽取测试：HTTP 200，`qwen3.8-flash` 正确抽取 3 条 claim（事实 2 条、传闻 1 条），`enable_thinking=false` 生效，单次 444 tokens。key 已写入本地 `.env`，未入库。

如果后续发现质量不够，备选：本地 Ollama（0 元，但占 5–10GB 磁盘），或用当前 Agent 代标并在 AI 记录里标注“AI 辅助标注”。

### 2.2 定英雄事件

演示只讲一个真实的“收购/澄清”事件。你可以：

- 直接指定一个标的/事件；或
- 让我从公开公告里挑 3 个候选，你选 1 个。

默认避开敏感人物、争议性丑闻和强监管事件，优先“收购对价传闻 → 公告 → 澄清/更正”这种结构完整的案例。

### 2.3 确认 iFinD 内容的公开使用边界

公开 demo 会展示公告/新闻的短引用和派生 claim。需要确认你的 iFinD 账号是否允许把摘录放到公开页面。

- 如果不确定：公开 demo 只用交易所/公司官网等公开权威材料，iFinD 只用于本地验证和数据比对。
- 如果允许：页面仍只展示必要摘录 + 原文链接，不全文转载。

这一条不阻塞开发，但会影响 fixtures 的选择。
